## 1. System Overview & Core Methodology

The D.S.Astro System is an empirical, deterministic predictive astrological methodology established by Astrologer T. Jeyashankar of Ayyan Astro Academy, Madurai.

### Core Calculation Flow:
1. **Current Dasa Lord** (தசா நாதன்)
2. **Sign Occupied by Dasa Lord** $\rightarrow$ **Temporary Lagna** (தற்காலிக லக்னம்)
3. **Lord of that Sign** $\rightarrow$ **Temporary Lagna Lord** (தசாநாதனுக்கு வீடு கொடுத்தவர்)
4. **House, Star Lord, Relationships, Sthana Balam, Aspects, Transits, Timing** $\rightarrow$ **Predictive Assessment**
